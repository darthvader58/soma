# Fixture workspace visual draft

This is a **draft without direction**: the user supplied a scientific and
functional plan but has not supplied or approved a brand/style direction.
The interface implementation is reviewable; this is not a final visual design.
Default dials: ENERGY 1 / RHYTHM 1 / MOTION 1.

The task is to inspect a scenario, request a delivery plan, and understand its
evidence. A scenario column sits beside the lunar viewport on a wide display;
the text result and shared time control follow. A phone presents the scenario,
viewport, and result in one flow. Medium widths use a compact two-column form
inside that flow. There is no general atlas navigation or unrelated dashboard.

Warm neutral panels support reading inputs and schedules. A dark viewport
reserves space for lunar imagery; without tiles it contains an explicit empty
state. Teal identifies the Plan delivery action. System sans-serif text keeps
the dense labels readable without a remote font request; tabular numerals
align times and byte counts. Rules and column alignment group the work, without
decorative cards, icons, photographs, glows, or generated imagery. The product
name is text. Only the content required by the project plan is displayed.

Controls use native labels and visible focus, 44-pixel targets, text status,
and no automatic animation. Time scrubbing changes the selected record rather
than starting a scientific calculation. Synthetic/assumed inputs and missing
analysis stay visible. Null results are shown as unknown, never zero.
