# Earth reference texture

Credit: NASA Earth Observatory. Blue Marble Next Generation, November 2004 static reference composite with topography and bathymetry, produced by Reto Stöckli. This is not current weather or simulated illumination.

Original unmodified 5400 × 2700 JPEG: `nasa-blue-marble-november-2004.jpg` (2,540,426 bytes).

SHA-256: `388422e3bfc62517af2a9d538989a2f859fc193e6f6cde72c3d230ef29c2e69f`.

[NASA source page](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/)

[Original image](https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-topography-bathymetry/november/world.topo.bathy.200411.3x5400x2700.jpg)

The renderer supplies the body's real WGS84 dimensions and uses exact Python Earth centers and ITRF93 orientation samples. Neutral unlit rendering shows reference geography; it does not calculate Earth lighting. A half-turn in texture longitude maps Cesium's +X texture seam to NASA's Greenwich center; it does not modify the supplied body-pose matrix.
