# Captured Phase 4 runs

`synthetic-direct/` and `synthetic-relay/` contain actual Python `plan_run`
outputs, generated by `npm --prefix web run sync:fixtures`. Their scenario and
contact sources remain the unchanged hand-checkable fixtures one level above.
`expected.json` is arithmetic reference data and is never substituted for a
solver result.

Each folder contains `run.json` (analysis inputs, native result, independent
replay and solver details), `result.json`, a versioned Python `summary.json`
and the exact exported `run.zip`. The ZIP has scenario/result JSON, a hash
manifest, contacts/schedule/energy/buffer CSVs, summary, metadata-only CZML,
structured Markdown, analysis inputs and replay evidence. Its member metadata
is fixed; repeated packaging of the same run gives identical bytes.

The direct 100 MiB case is `infeasible_in_model` with a proven infeasible
discretized model. Its 307,200,000-bit capacity upper bound is smaller than
the 838,860,800-bit file. The relay case is `feasible_under_assumptions` with
`feasible_incumbent`, 104,857,600 unique delivered bytes and successful replay.
Optimality remains unproven. These are synthetic assumed-rate tests, not lunar
mission predictions, booked service or operational relay trajectories.

The solver uses 16 MiB chunks (including a final 4 MiB chunk), event-aligned
five-second bins and a shared 15-second solve budget. Rounded payload ends
reserve additional radio time and energy. Therefore the capture is not the
continuous 419.4304-second uplink / 83.88608-second downlink hand schedule.
Time limits can produce a different incumbent on another machine.

To validate the recorded relay without solving again:

```sh
.venv/bin/python -m soma replay fixtures/phase-4/synthetic-relay/run.json
```

To calculate a fresh package without altering these captures:

```sh
.venv/bin/python -m soma run fixtures/synthetic-relay/scenario.json --output-dir /private/tmp/soma-reproduced-run
```

The numerical DEM reference still has unknown horizons. No missing terrain
sample was filled to obtain this synthetic success. These captures cannot be
used as a physical site/date comparison.
