SOMA stands for **Selenographic Observation and Mission Atlas**. It provides a Python lunar analysis library and an interactive Moon workbench with two analysis tools. **Geometry** calculates new multi-site Sun/Earth geometry and reconstructed LRO states. **Data delivery** calculates terrain-backed, energy-constrained schedules in a bounded south-polar region. Contact capacity, radio conflicts, propagation delay, finite storage and lander energy constrain delivery.

The distribution is `soma-lunar`; import it as `soma`. The current repository version is **0.1.0**. Use the [installation guide](/getting-started/installation) and calculate your [first synthetic delivery plan](/getting-started/quickstart) with installed fixtures and no scientific-data downloads. For physical geometry, prepare the pinned sources for a [live geometry study](/getting-started/live-research).

## Read the outcome correctly

The Geometry tool reports completed **geometry studies**. Its plots show Sun/Earth center elevation and its scene replays stored spacecraft positions. That endpoint uses a reference sphere and does not evaluate terrain visibility. The Data delivery tool calls the numerical terrain provider and scheduler separately. See [analysis and map behavior](/guides/analysis-and-map) and the [delivery tutorial](/getting-started/live-delivery) for the distinction.

A delivery-planning result reports `feasible_under_assumptions`, `infeasible_in_model`, or `unknown`. Solver status and model fidelity are separate fields. A feasible schedule using assumed radio rates remains an assumed-rate simulation.

The browser displays engine-authored results. Public geometry and delivery calculations are bounded synchronous requests on Vercel; the local service additionally exposes planning jobs. Geometry completion does not imply delivery feasibility. A rendered shadow or visible line is not a scientific result.

SOMA is a planning model under declared assumptions. It does not reserve communications service, certify navigation or landing safety, or predict mission success. Read the [scientific limitations](/science/assumptions-limits) before interpreting a schedule.
