SOMA answers when a declared lander can deliver a finite dataset to Earth, through which contacts, and where the data waits. The Python engine constrains the schedule with contact capacity, radio conflicts, propagation delay, finite storage, and lander energy.

The distribution is `soma-lunar`; import it as `soma`. The current repository version is **0.1.0**. Install from source using the [installation guide](/getting-started/installation), then calculate a [synthetic example](/getting-started/quickstart) without downloading lunar datasets.

## Read the outcome correctly

A result reports `feasible_under_assumptions`, `infeasible_in_model`, or `unknown`. Solver status and model fidelity are separate fields. A feasible schedule using assumed radio rates remains an assumed-rate simulation.

The browser displays engine-authored results. The public application can show captured physical runs and a registered Moon display; arbitrary new analysis requires the Python engine and its datasets. A rendered shadow or visible line is not a scientific result.

SOMA is a planning model under declared assumptions. It does not reserve communications service, certify navigation or landing safety, or predict mission success. Read the [scientific limitations](/science/assumptions-limits) before interpreting a schedule.
