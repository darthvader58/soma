Use the [six-minute workbench recording guide](/guides/workbench-demo) for the current public application. It covers multiple sourced locations, reconstructed LRO states, a custom coordinate, a controlled date comparison and reproducible JSON export.

The earlier captured delivery demonstration is retained in the repository's [historical recording script](https://github.com/darthvader58/soma/blob/main/soma/docs/hackathon-demo-script.md) for offline reproduction. Its screen instructions do not describe the current public dashboard. For current delivery-planning functions, start with the [Python quickstart](/getting-started/quickstart).
