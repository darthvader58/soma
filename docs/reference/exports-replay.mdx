---
title: Exports and independent replay
description: Preserve the exact calculation and verify a schedule without rerunning optimization.
---

## Create a package

```python
from pathlib import Path
from soma.engine import plan_run
from soma.exports import create_run_package
from soma.validation import load_scenario

run = plan_run(load_scenario("fixtures/synthetic-relay/scenario.json"))
Path("run.zip").write_bytes(create_run_package(run))
```

The package preserves scenario and result JSON, summary, contacts and schedule CSVs, energy and buffer histories, display CZML and structured display data, renderer registration, a Markdown explanation, and a checksummed run manifest. Analysis inputs and replay evidence are included when present; the pinned conversion manifest is included when applicable.

CSV headers state units. An empty CSV field represents unknown, never zero. Source-transmit intervals, receiver occupancy, and byte availability remain separate columns.

`create_run_package` checks the scenario/result hash relationship. The ZIP is byte-stable for the same supplied run and export environment. This does not promise that a fresh time-limited optimization produces the same allocation.

## Replay the saved schedule

```bash
python -m soma run fixtures/synthetic-relay/scenario.json --output-dir /tmp/soma-relay
python -m soma replay /tmp/soma-relay/run.json
```

Replay checks the selected allocations against usable contacts, payload capacity, byte conservation, causal forwarding, finite buffers, both endpoints' radio occupancy, modeled energy, and last-byte deadline. It does not invoke the optimizer to repair an invalid schedule.

## Verify the full archive

```bash
python -m soma.verification.exports /tmp/soma-relay/run.zip
```

Package verification checks export contents and checksums and recomputes consistency and replay evidence. A structurally valid JSON document is not sufficient evidence of a valid delivery schedule.

Older captured packages can predate the current required display artifacts even when their numerical schedules pass replay. Generate a fresh package to satisfy the current complete-export contract. Do not silently change an archived package's result to make it pass a newer verifier.

## Reproduce physical evidence

Acquire the pinned data and use the [physical reproduction workflow](/getting-started/physical-runs). Preserve scenario, software and dataset hashes, scheduler options, assumptions, and solver status when comparing runs. Source URLs and checksums identify scientific inputs without implying permission to redistribute kernels, licensed tiles, or restricted papers.
