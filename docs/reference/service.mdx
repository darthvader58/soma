---
title: Local HTTP service
description: Submit isolated planning jobs and retrieve immutable results from the Python engine.
---

The FastAPI service is intended for local use. It runs jobs in separate Python processes so one SPICE kernel configuration cannot contaminate another.

```bash
source .venv/bin/activate
uvicorn soma.api.app:app --host 127.0.0.1 --port 8000
```

Interactive API documentation is available at `http://127.0.0.1:8000/docs`. The local paths below do **not** include the frontend development proxy's `/api` prefix.

## Submit and poll

```bash
curl --request POST http://127.0.0.1:8000/plans \
  --header 'Content-Type: application/json' \
  --data-binary @fixtures/synthetic-relay/scenario.json
```

A successful submission returns HTTP 202 with `job_id` and `scenario_sha256`. Poll `GET /plans/{job_id}` for status, progress stage, and the completed immutable result. Match the returned scenario hash to your request before displaying it.

| Endpoint | Purpose |
| --- | --- |
| `POST /plans` | Validate and queue a complete scenario |
| `GET /plans/{id}` | Inspect job status, stage, and result |
| `DELETE /plans/{id}` | Request cancellation and stop avoidable work |
| `GET /plans/{id}/export` | Download the completed ZIP package |
| `GET /plans/{id}/summary` | Read the structured summary |
| `GET /plans/{id}/display` | Read display CZML |
| `GET /plans/{id}/display-data` | Read the derived display data |
| `GET /plans/{id}/renderer-registration` | Read the run's versioned registration |

Exports and derived display endpoints require a completed job; early requests return HTTP 409. Invalid scenarios return HTTP 422. Request and retention limits are enforced; exceeding retained job capacity returns HTTP 429. Export runs you need to keep before restarting the service.

## Local frontend

```bash
npm --prefix web ci
npm --prefix web run dev
```

Open `http://127.0.0.1:5173`. The development server forwards `/api` to the local Python service. Edited inputs invalidate the previous result; a failed live request must not substitute a captured schedule.

## Hosted display boundary

The repository-root Vercel adapter in `api/index.py` serves only `/api/moon/registration`, `/api/moon/conversion`, and `/api/moon/tiles/*`. It reuses the registered display conversion and requires authorized ion access. It does not host `/plans` or perform new numerical analysis.

The hosted application uses exact captured engine runs. A public live planner needs a separate service deployment with an appropriate persistence, worker, resource, and access model.
